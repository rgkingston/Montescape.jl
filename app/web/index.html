Friction surface settings
What is the friction surface?

A friction (resistance) surface is a raster where each cell value represents the cost of moving through that cell. It is the input to LCP, LCC, and Circuitscape. The framework always builds it from a weighted combination of layers; Monte Carlo perturbs the weights, so a prebuilt friction surface is not supported. All enabled layer weights must sum to 1.0.

Terrain ruggedness (TRI)
What is TRI?

TRI (Riley 1999) measures local variability in elevation. High TRI = rough, broken terrain. Adding a small TRI weight (~0.05) penalises broken ground that pure slope misses.

friction.tri.enabled

Aspect (directional preference)
What is aspect?

Each cell's aspect is the compass direction the slope faces. This layer penalises cells whose aspect points away from your preferred direction (e.g. north-facing slopes if you prefer south-facing for snow-melt reasons). 0° = north, 90° = east, 180° = south, 270° = west.

Vegetation / land cover
How does the reclass work?

The vegetation layer reads an integer-coded land-cover raster and reclassifies each code to a friction value 1–10. Enter one mapping per line as oldcode=newvalue, e.g. 1=1 for forest, 2=3 for shrub, 3=7 for bare rock.

Custom layers (user-written)
How do I add a custom layer?

Write a Julia file that calls register_layer!("my_layer", fn) where fn(dem, res, cfg) returns a Matrix{Float32} clipped to [0, 2]. Then add a row below with the absolute path to that file and the same name you passed to register_layer!. One row per layer. The Hannibal case study under case_studies/hannibal/custom_layers/ ships three worked examples (elephant terrain, elephant altitude, ambush risk).

friction.custom_layers[] + friction.custom_layer_files (derived)
Least-Cost Path (LCP)
What is LCP?

The single optimal route from Start to End that minimises accumulated cost across the friction surface. One line per route. Pure-Julia Dijkstra implementation.

lcp.enabled
lcp.knight
Least-Cost Corridor (LCC)
What is LCC?

LCC identifies the zone of near-optimal paths within a threshold of the LCP cost (e.g. "all routes within 5% of the optimum"). Output is a raster mask. Use it when the single best path is not robust to small data errors.

Circuitscape (circuit theory)
⚠ Heavy computation. Memory requirements scale rapidly with grid size; users should expect high memory usage (=10-100+ GB) for regional-scale rasters and enable HPC resources accordingly.
What is Circuitscape?

Circuitscape treats the landscape as an electrical circuit and reports current flow through each cell. advanced supports source + ground rasters (default for this pipeline); pairwise connects all point pairs; one-to-all connects one focal point against all others.

Monte Carlo ensemble
What does Monte Carlo do?

Each iteration re-runs the entire pipeline with a freshly sampled friction-weight vector and (optionally) a perturbed DEM consistent with the published vertical accuracy of your DEM product. The result is a probability-of-use surface and confidence intervals, not a single line.

Sensitivity analysis (Morris)
What is Morris sensitivity?

The Morris elementary-effects method ranks each friction layer by how much it changes the output. Use it to identify which layers actually matter for your study area. Trajectories = repetitions of the one-at-a-time scan (10 is a reasonable minimum); levels = number of discrete weight levels per layer.

monte_carlo.sensitivity.morris

Tells you which friction layer matters most in your study area.

Pass-crossing aggregation
How is this different from the route buffer?

After MC finishes, the pipeline draws a circle of this radius around each candidate pass point and counts how many iterations' least-cost paths enter it. This is different from the per-route buffer_m on the Routes tab, which controls the size of the source/ground region before path-finding runs.
